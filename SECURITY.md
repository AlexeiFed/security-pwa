# 🔒 Инструкции по безопасности

## ⚠️ ВАЖНО: Утечка секретов

**ВНИМАНИЕ**: В этом репозитории была обнаружена утечка секретов через файл `.env`, который был закоммичен в Git. Все API ключи и токены были скомпрометированы.

## 🚨 Немедленные действия

### 1. Смените ВСЕ ключи и токены:

- **Firebase API ключи** - в консоли Firebase
- **Yandex Maps API ключ** - в личном кабинете Yandex
- **CallDog API ключ** - в личном кабинете CallDog
- **VAPID ключи** - сгенерируйте новые
- **OneSignal App ID** - в консоли OneSignal

### 2. Проверьте использование ключей:

- Проверьте логи серверов на подозрительную активность
- Мониторьте использование API ключей
- Проверьте биллинг аккаунтов

## 🛡️ Предотвращение будущих утечек

### Правила работы с секретами:

1. **НИКОГДА не коммитьте файлы с секретами:**
   - `.env`
   - `serviceAccountKey.json`
   - Любые файлы с API ключами

2. **Используйте .env.example:**
   - Копируйте `.env.example` в `.env`
   - Заполните реальными значениями
   - `.env` уже добавлен в `.gitignore`

3. **Проверяйте перед коммитом:**
   ```bash
   git status
   git diff --cached
   ```

4. **Используйте pre-commit hooks:**
   ```bash
   npm install --save-dev husky
   npx husky add .husky/pre-commit "git diff --cached --name-only | grep -E '\.(env|key|secret)' && exit 1 || exit 0"
   ```

## 🔍 Проверка безопасности

### Сканирование на секреты:
```bash
# Проверка истории Git
git log --all --full-history -- .env

# Поиск секретов в коде
grep -r "api_key\|secret\|token" --exclude-dir=node_modules .
```

### Инструменты для проверки:
- [GitGuardian](https://gitguardian.com/) - автоматическое сканирование
- [TruffleHog](https://github.com/trufflesecurity/trufflehog) - поиск секретов
- [GitLeaks](https://github.com/zricethezav/gitleaks) - сканирование репозиториев
